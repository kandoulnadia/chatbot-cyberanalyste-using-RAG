chatbot cyberanalyste is a state-of-the-art Cyber Threat Intelligence (CTI) assistant built on a Retrieval-Augmented Generation (RAG) architecture designed to transform raw, unstructured data from underground forums into actionable security insights. By integrating a FAISS vector database with Sentence Transformers, the system performs high-speed semantic searches to retrieve critical context—such as threat actor profiles, specific attack vectors, and danger scores—which is then processed by advanced large language models like Llama 2 or Mistral. To ensure seamless deployment in resource-constrained environments like Kaggle, the project implements 4-bit quantization via the BitsAndBytes library, enabling 7B-parameter models to maintain high reasoning accuracy with a significantly reduced memory footprint. The entire workflow is accessible through an intuitive Gradio interface, providing security analysts with a powerful platform to synthesize complex cyber threats into clear, structured, and tactical recommendations.
